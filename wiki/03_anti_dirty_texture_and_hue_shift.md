# 03. 反髒貼圖法與四階色相偏移 (Anti-Dirty-Texture & Hue-Shift)

> **所屬知識庫**：ANTI Academy // Blockbench 3D 體素工坊  
> **核心案例**：沙漠哨兵・狐獴 (Suricata suricatta)  
> **關鍵概念**：1:1 像素簇（Pixel Clusters）、四階色相偏移色板、防髒貼圖鐵律

---

## 1. 什麼是「反髒貼圖法」（Anti-Dirty-Texture Law）？

在 Minecraft 模組界，最糟糕的貼圖通常來自兩大陷阱：
1. **直接貼入噪點／高頻雜訊**：使用 Photoshop 濾鏡或隨機雜色筆刷，導致方塊看起來像「發霉的電視雜訊」。
2. **AI 生圖直接映射**：將 2D AI 圖像烘焙到 UV，產生嚴重拉伸、光影混亂與像素密度不一致（Pixel Density Mismatch / Mixels）。

**ANTI 工坊鐵律**：
- **PPU = 1.0 絕對統一**：模型的每個方塊表面，像素比例嚴格維持 1u = 1px，全模型無局部拉伸。
- **2~4px 乾淨像素簇（Pixel Clusters）**：像素不單獨孤立存在，必須以 2 × 2 或 3 × 2 的結構化色塊組裝，呈現清晰的塊狀節奏。

## 2. 狐獴專屬：四階色相偏移沙漠毛皮色板（4-Step Palettes）

單純調整亮度（Brightness）的單色調（Monochromatic）著色會讓生物看起來死氣沉沉。ANTI 學院採用 **「色相偏移（Hue-Shift）」** 著色法：
> **「暗部往冷色調走（Cooler Shadows），高光往暖陽光走（Warm Highlights）。」**

狐獴毛皮切分為三套專屬四階色板：

### (1) 沙漠淺霜腹部色板（Cream Palette - 腹部、口鼻、腳掌內側）
*以溫暖晨光米白為基底，暗部帶有淡灰褐，高光帶有象牙金：*
- **Step 0 (暗部)**：`RGB(182, 158, 126)` —— 乾草灰褐
- **Step 1 (過渡)**：`RGB(218, 196, 160)` —— 暖沙米黃
- **Step 2 (主色)**：`RGB(238, 220, 188)` —— 沙漠淡乳酪
- **Step 3 (高光)**：`RGB(248, 234, 208)` —— 烈日象牙白

### (2) 沙棕背脊毛皮色板（Tan Palette - 體側、四肢外側、頸部）
*模擬乾燥荒漠砂岩的層次，色相從赭褐跨越到金黃：*
- **Step 0 (暗部)**：`RGB(118, 88, 60)` —— 深焦赭褐（冷陰影）
- **Step 1 (陰影)**：`RGB(156, 120, 84)` —— 陶土土黃
- **Step 2 (主色)**：`RGB(186, 150, 110)` —— 沙漠金褐
- **Step 3 (高光)**：`RGB(212, 178, 136)` —— 陽光暖棕金

### (3) 特徵暗斑色板（Dark Accent Palette - 黑眼圈、耳廓尖、尾尖、背部條紋）
*狐獴最重要的防眩光黑眼圈與標誌性背紋：*
- **Step 0 (極深)**：`RGB(32, 24, 22)` —— 濃郁黑褐（瞳孔與爪尖）
- **Step 1 (深影)**：`RGB(54, 42, 38)` —— 炭焙黑褐（眼眶防眩光環）
- **Step 2 (過渡)**：`RGB(78, 62, 54)` —— 苦巧克力褐（背脊斑紋輪廓）
- **Step 3 (微亮)**：`RGB(104, 84, 72)` —— 柔和暗栗色

## 3. 結構化背紋矩陣（Dorsal Dark Banding）

在狐獴的背部（`mk_chest` 與 `mk_pelvis` 的 North 面），我們使用像素矩陣繪製間隔條紋，嚴禁隨機噴槍：

```
Chest (North 6x6):           Pelvis (North 6x6):
[ 1 1 2 2 1 1 ]              [ D D D D D D ] <- 條紋 2
[ D D D D D D ] <- 條紋 1    [ 1 1 2 2 1 1 ]
[ 1 2 2 2 2 1 ]              [ D D D D D D ] <- 條紋 3
[ D D D D D D ] <- 條紋 2    [ 1 2 2 2 2 1 ]
[ 1 2 2 2 2 1 ]              [ D D D D D D ] <- 條紋 4
[ 0 1 1 1 1 0 ]              [ 0 1 1 1 1 0 ]
```
*(代碼：D = 深色條紋 Dark_1, 0 = 陰影 Tan_0, 1 = 主色 Tan_1, 2 = 亮面 Tan_2)*

這種精確的矩陣排布保證了：無論視角如何縮放旋轉，條紋都保持極致俐落的體素雕刻感，絕無貼圖模糊與混濁。
